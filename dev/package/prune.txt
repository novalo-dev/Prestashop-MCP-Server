# Parts of the Composer dependencies left out of the module archive, one path
# per line, relative to vendor/. Read by both builds and by the dependency job
# of the CI, which checks that every class left in still loads.
#
# What goes here is code the built-in assistant never calls and that would
# put shell, process or eval calls in a merchant's shop for nothing: running a
# local MCP server, the file system and database toolkits, evaluation, the
# command line, the test fakes. Also the adapters for libraries the module
# does not ship (Guzzle, Amp, Laravel, Redis).
#
# src/RAG stays: the assistant's memory is built on it. A path that the
# module's own code names is refused by dev/package/loads.php, so pruning a
# part still in use fails the CI instead of a merchant's chat.
